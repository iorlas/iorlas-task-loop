## Top 10 by importance

1. **DESIGN-OPUS-01**: an older delegate that meets a newer `state.json` field wipes every lease, hold, out mark and auth entry, and the system runs mixed delegate versions by design.
2. **DESIGN-OPUS-11**: the "factory" is a launcher that exits. Nothing restarts a lane that dies, so a crash at 01:00 in Trust Night stays a dead lane until morning.
3. **DESIGN-OPUS-15**: 353 red-suite logs against 231 releases in six days. The release suite is the real gate, and the engine's land gate keeps disagreeing with it.
4. **DESIGN-OPUS-02**: run control flow is exceptions reached through the host object (`e.Blocked`, `Exec(BaseException)`), which hides the dependency from the import rules and makes the step graph impossible to draw.
5. **DESIGN-OPUS-18**: the service locator is the biggest single driver of test volume (144 Protocols, 778 + 765 lines of host fakes). Z16 is mis-ranked as wave 3.
6. **DESIGN-OPUS-03**: the Git port mirrors the git CLI (72 methods), so tests carry a 1,757-line git simulator. Meanwhile 4,511 vendored lines of `git_porcelain` ship in every install and no runtime code imports them.
7. **DESIGN-OPUS-09**: the dashboard decides it is stale by hashing only its own package. The engine code it loads and writes through (Intake, owner requests, bd) can be any older version.
8. **DESIGN-OPUS-13**: slots are bd beads with 60-second heartbeats. The issue tracker that syncs to GitHub doubles as a lease server, and `.beads` is 203M.
9. **DESIGN-OPUS-05**: there are five vocabularies for how a run ended (`Kind` 29 values, `Outcome`, `Result`, `WhyCode`, `Cause`), one dead value, and two crash kinds.
10. **DESIGN-OPUS-07**: a verb's edge is spread over four layers (`tl.py`, `cli/`, `app/wire`, `app/launch`), with three composition roots allowed to import everything. `tl.py` doubled in four days and reaches the engine, judge and check only through `importlib` strings.

## What I think you are NOT thinking about
