## Top 10 by importance

1. **DESIGN-FABLE-24** The release cadence is the design: 237 releases in 7 days turn every version hop (Z05/Z12/Z13/Z14/Z21) into a 34-times-a-day event and make "version" useless as a compatibility unit.
2. **DESIGN-FABLE-01** `Engine` is one object with ~80 flat fields plus 38 lazily built parts that all get the whole engine; there is no component to draw, only one box with dotted arrows (agrees Z16, adds the field census).
3. **DESIGN-FABLE-02** Two injection dialects coexist: 145 narrow Protocols (76 in `land`) versus `host: Any` in 36 modules; the Protocols are faces of the same object, not seams, so the diagram cannot show them as boundaries.
4. **DESIGN-FABLE-13** Five in-app vocabularies for "how it ended" (`Outcome`, `Result`, `WhyCode`, `Cause`, `Kind`×28) before delegate's stop reasons even arrive; Z07 fixes the cross-app half only.
5. **DESIGN-FABLE-08** `taskloop.contracts` is the dumping ground: records, ports, file stores, bd mutation, reconciliation, the dashboard's wire types; "dash imports contracts only" holds because the dashboard's own types were moved into the engine.
6. **DESIGN-FABLE-10** Delegate has a typed 209-line router inside a stringly-typed shell: `Decision.as_dict()` at `dg:app/decide.py:147`, then `d["how"]`, `h["kind"]` through `run.py` and `launch.py`.
7. **DESIGN-FABLE-12** `RunRequest` exists on both sides of the subprocess arrow with different fields and different argv builders; the one arrow in the C4 has two labels.
8. **DESIGN-FABLE-23** The architecture is enforced by 1,786 lines of allowlist ratchets on text patterns plus a 484-line `.importlinter`; none states "one writer per file family", the invariant every P1 broke.
9. **DESIGN-FABLE-16** Process state travels through module attributes set from other modules (`engine_lock.LOCK = lock`, `RUN_HALT["ev"]`, `RUN_SLOT["owned"]`); the mutable-global rule cannot see it.
10. **DESIGN-FABLE-07** Two store layers named "stores": `taskloop.contracts.stores` (the real file I/O) and `taskloop.stores` (a bundle over it); the layer diagram draws them in the wrong order.
