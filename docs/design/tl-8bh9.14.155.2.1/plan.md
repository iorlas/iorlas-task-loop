## Size
Estimate: 20 changed files, including new source, focused tests, their fixture, existing integrations and this plan; three independently testable behaviours; 65 model calls for one implement attempt. This is within the limits of 60 files, three independent behaviours and 100 calls.

1. Durable admission: two requests for the same checked source admit one operation and one reservation, with immutable source/target and retained agent inputs. Acceptance: competing admissions, stale checks, conflicting land candidates and a failed transaction cannot create duplicate work or leave a partial reservation; incompatible schema state is refused without modification.
2. Detached execution: the admitted operation resolves a supported textual conflict through the pinned merge API. Acceptance: the result has the recorded parents and provenance, retains automatic changes, leaves the checked task branch unchanged, and remains in the reserved detached worktree without checks, push or task completion.
3. Restart adoption and bounded execution: reopening an intact database continues the same operation and accounts for its original executions. Acceptance: injected interruptions adopt matching merge effects and captured results, live/unknown owners prevent duplicate execution, and three spent executions reach a durable terminal result without a fourth run.
